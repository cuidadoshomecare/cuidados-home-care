# Cuidados Home Care

Site institucional em React + Vite + TypeScript, preparado para deploy na Netlify.

## Desenvolvimento
- `npm install`
- `npm run dev`
- `npm run build`

## Antes de publicar
Revise e substitua os dados marcados como pendentes no conteúdo:
- número oficial do WhatsApp;
- cidade e bairros atendidos;
- serviços efetivamente oferecidos e limites de atuação;
- razão social/CNPJ e contato do controlador de dados, se aplicável;
- política de privacidade e processo de atendimento de solicitações LGPD.

Não publique alegações sobre equipe, credenciais, disponibilidade, depoimentos ou cobertura geográfica sem confirmação documental.

## Netlify
Build command: `npm run build`
Publish directory: `dist`
